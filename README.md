# School Management System

## Description

School Management System is a Python-based project that manages students, teachers, and courses using Object-Oriented Programming (OOP) concepts.

The system allows users to add students, add courses, enroll students in courses, display information, and store data using JSON files.

---

## Features

- Add new students
- Add new courses
- Enroll students in courses
- Display students information
- Display courses information
- Manage teachers information
- Save and load data using JSON files
- Handle errors using exception handling

---

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- JSON File Handling
- Git & GitHub
